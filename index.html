The math crap they're counting on.

The SAT doesn't test whether you can do the math. It tests whether you'll fall for the same twelve traps as everyone else. Here they are, fixed in two lines each.

x² + y² − 6x + 4y − 12 = 0 is a circle. What is its radius?

  1. A) 5
  2. B) 12
  3. C) 13
  4. D) 25
that's r², not r

The 12 traps

Each one shows up on almost every test, and each one has a wrong answer waiting for you in the choices. Cross it out before you start.

  1. The radius is the square root

    (x−3)² + (y+2)² = 25, so r = 25The right side is r². Radius is 5. And the center is (3, −2): signs flip.

  2. "Exactly one solution" means the discriminant is zero

    One solution, so x = 1Set b² − 4ac = 0 and solve for the unknown constant.

  3. The minimum value is the y, not the x

    Vertex at x = 3, so the minimum is 3Plug x = −b/(2a) back in. The minimum is f(3), not 3.

  4. Percents multiply, they don't add

    Up 25% then down 20% = up 5%1.25 × 0.80 = 1.00. No change at all.

  5. Inside the parentheses is backwards

    f(x − 2) moves the graph left 2f(x − 2) is RIGHT 2. Only the "+3" outside goes the way it looks (up 3).

  6. Squaring creates fake answers

    √(2x + 7) = x + 2, so x = 1 and x = −3Check both in the original. −3 gives 1 = −1. Only x = 1.

  7. "No solution" doesn't mean you solved it wrong

    (x+3)/(x−2) = 5/(x−2), so x = 2x = 2 makes the denominator zero. No solution is the answer.

  8. A zero at 3 is the factor (x − 3)

    p(3) = 0, so (x + 3) is a factorFactor theorem: p(a) = 0 means (x − a). Sign flips.

  9. Area scales by k², volume by k³

    Sides 1.5× bigger, so area is 1.5× biggerArea is 2.25× bigger. Double a sphere's radius and volume goes up 8×.

  10. Infinitely many solutions = the same line

    Set the two equations equal and solveMake one equation a multiple of the other. Coefficients AND constants must match. If only the coefficients match, it's no solution.

  11. The outlier moves the mean, not the median

    3, 5, 5, 8, 9, 30 — "cannot be determined"Mean 10, median 6.5. Big high value → mean > median. You never need to compute standard deviation, just compare spread.

  12. The slope is "per," the intercept is "start"

    C = 45 + 0.20m, so 45 is the cost per mile0.20 is the cost per mile (it multiplies m). 45 is the fee when m = 0.
